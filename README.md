# WYCHaochan-Password-Generator

**皓叶草密码生成器**

一个基于 C# 和 .NET 8 开发的密码生成器（Windows 控制台程序）。

本项目旨在帮助用户快速生成高强度随机密码，以满足网站、应用程序及各类账户的安全需求。

程序将使用 .NET 提供的密码学安全随机数生成器（CSPRNG）生成密码，使生成结果具有较高的随机性和不可预测性，可用于日常账户密码生成场景。

## 功能

- 自定义密码长度
- 支持数字、大小写字母
- 可选特殊字符
- 基于密码学安全随机数生成器
- 开源免费

## 开发环境

- .NET 8
- C#
- Visual Studio 2022
